### 3\. TECHNICAL \& OFFLINE PWA ARCHITECTURE (CRITICAL FOR iPHONE)

1. **Real Working Pre-loaded Catalog + Online Search + Local Import**:

   * Pre-populate the default songs (*Satu Bulan - Bernadya*, *Die With A Smile - Lady Gaga \& Bruno Mars*, *Waktu yang Salah - Fiersa Besari*, *Until I Found You - Stephen Sanchez*, *Sunflower - Post Malone*, *Another Love - Tom Odell*) with high-resolution cover art, complete Indonesian/English lyrics, and real working audio streams (automatically query iTunes API / Jamendo / reliable CORS-friendly MP3 streams on startup so every single default song plays real audio immediately when clicked).
   * Provide a **1-Click "Download for Offline"** button on every song.
2. **True Offline Storage Engine (`IndexedDB`)**:

   * Create a robust `MuseeOfflineDB` using native `IndexedDB` with stores for `tracks` (storing the raw Audio `Blob`, cover image `Blob`/DataURL, title, artist, album, duration, and lyrics) and `playlists`.
   * When a user clicks **Download** on any online track:

     1. Fetch the audio file as a `Blob` (with a visual download spinner/progress indicator).
     2. Save the `Blob` and metadata into `IndexedDB`.
     3. Mark the track with a **"Downloaded ✓"** badge.
   * When a user **Imports Local MP3/M4A files** from their iPhone:

     1. Read the `File` objects directly as `Blob`s and store them permanently in `IndexedDB`.
     2. Immediately add them to "Your Library" and "Downloaded Songs" so they work 100% offline in Airplane Mode.
   * **Offline-First Playback Resolver**: Whenever a song is played, check `IndexedDB` first. If the audio `Blob` exists locally, play it via `URL.createObjectURL(blob)` with zero network usage.
3. **iPhone Background Audio \& Lock Screen Controls (`MediaSession API`)**:

   * Integrate `navigator.mediaSession` so when a song plays, the iPhone Lock Screen, Notification Center, and Dynamic Island display the song title, artist, high-res album artwork, and working Play, Pause, Previous, Next, and Seekbar controls.
4. **iOS PWA Standalone Setup**:

   * Include `<meta name="apple-mobile-web-app-capable" content="yes">`, `<meta name="apple-mobile-web-app-status-bar-style" content="default">`, `<meta name="apple-mobile-web-app-title" content="Musee">`, a dynamic Web App Manifest, and Service Worker registration for offline app-shell caching.
